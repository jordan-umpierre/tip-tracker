# Privacy Policy for Tip Tracker

Effective 2026-08-06.

Tip Tracker is a shift and tip logging app for iOS and Android. This policy
describes what the app stores, where it goes, and how to get rid of it. It
covers the app and the Tip Tracker API that supports optional cloud accounts.

This document is written from the code it describes, not from a template. If
the code and this file ever disagree, the code is the bug and this file is the
promise.

## The short version

- The app works entirely on your device. An account is optional.
- Without an account, nothing you enter leaves your phone.
- With an account, your shift records are copied to a server so a second
  device, or a replacement phone, can have them.
- There is no advertising, no analytics, no tracking, and no third party that
  receives your data for its own purposes.
- Your data is never sold and never shared for marketing.

## What the app stores on your device

Everything you enter is written to a SQLite database on the device:

- **Jobs**: name, hourly rate, and whether an overtime estimate is turned on,
  with the workweek boundary it uses.
- **Shifts**: date, optional start and end times, duration, tips, the hourly
  rate the shift was worked at, and any note you write.
- **Federal withholding settings**: the values from your W-4 — filing status,
  pay frequency, the Step 2 checkbox, the Step 3 and Step 4 amounts, and
  whether the form claims exempt — along with the first pay date each set of
  values applies to.

Two things are deliberately **not** stored. When you use the withholding
estimator, the federal taxable wages you type from your paystub and the
estimate it produces are both discarded when the screen closes. Neither is
written to the database, sent anywhere, or included in a backup.

You can export everything as a CSV or a JSON backup to a folder you choose.
Those files are yours; the app never uploads them.

## What happens if you create an account

Cloud accounts are optional. The app is fully usable without one, and the sign
in screen can be ignored forever.

If you create one:

- **Your email address and password** are held by Supabase Auth, the
  authentication provider. The app never stores your password.
- **Your jobs, shifts, and withholding settings** are copied to the Tip Tracker
  database so they can be restored or synced to another device. These are the
  same fields listed above.
- **A device identifier** generated by the app on first launch, used so the
  server can tell which device sent a change and can safely ignore a duplicate
  of one it already recorded. It is not an advertising identifier, and it is
  not tied to any identifier the operating system assigns.
- **Timestamps** recording when each record was created and last changed.

Your data is only ever associated with your own account. The server derives
your account from the signed token on each request; a request cannot ask for
another account's records.

## Server logs

The API writes one line per request containing the HTTP method, the path, the
response status, how long the request took, and — once your token has been
verified — your account identifier. Request bodies, query strings, and
authorization headers are never logged, so your earnings and your tokens do
not appear in them.

Your IP address is used in memory to limit how many requests one address can
make per minute. It is not written to the request log.

## Who else receives data

Two service providers process data on Tip Tracker's behalf, and only to run the
service:

- **Supabase**, for account authentication and email delivery.
- The **API and database host**, for running the server and storing the
  synced records.

There are no analytics SDKs, no advertising SDKs, no crash reporting services,
and no data brokers. No data is sold, and none is shared for advertising or
any other party's purposes.

## Deleting your data

- **Delete the cloud account**: Settings → Cloud account → Delete cloud
  account. This removes your account and its records from the server and asks
  the authentication provider to remove the identity. It cannot be undone. The
  jobs and shifts on your device are kept, and the device can connect to a new
  account afterward.
- **Delete the local data**: uninstalling the app removes its database from
  the device. Individual jobs and shifts can also be removed inside the app.

Deleted cloud records are removed when you delete the account. A record of the
deletion itself is retained so a device that has been offline learns the record
is gone rather than restoring it. Ordinary encrypted backups taken by the
database host may hold deleted content until they age out on the host's own
schedule.

## Children

Tip Tracker is meant for people who work for wages and is not directed to
children under 13. Accounts are not knowingly created for them.

## Security

Traffic between the app and the server uses HTTPS. Your saved login is stored
in the iOS Keychain or the Android Keystore rather than in ordinary app
storage. Access to the server database is limited to the accounts that run the
service.

No system is perfect, and this one is maintained by one person. If you find a
security problem, please report it to the contact address below.

## Changes to this policy
