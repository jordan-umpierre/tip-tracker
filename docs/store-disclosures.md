# Store privacy answers

These answers describe the local-only iOS launch build. Revisit them before a
future release if accounts, analytics, crash reporting, or advertising are
added.

## Apple — App Privacy

| Data type | Collected | Linked to user | Tracking | Purpose |
|---|---|---|---|---|
| Email address | No | — | — | No account feature ships |
| User content (jobs, shifts, settings) | No | — | — | Stored only on the user's device |
| Device ID | No | — | — | No cloud service ships |
| Crash, performance, analytics | No | — | — | No SDK collects them |
| Financial info (payment) | No | — | — | The app takes no payments |
| Location, contacts, photos, health, browsing | No | — | — | Never requested |

Tracking is **No**. The app does not advertise, profile, or send data to a
server.
